omero-duplicator
=================

This project's real README is `README.md <README.md>`_ - written in
Markdown for GitHub rendering. This file exists only to satisfy the
OMERO integration test suite's ``rst-lint`` check, which chokes on
Markdown's fenced code blocks (``rst-lint`` has no concept of them, and
misreads the triple backticks as malformed RST inline markup) - see
``ome/omero-test-infra``'s ``py-check`` script, which lints
``README.rst`` instead of ``README.md`` whenever this file is present.
